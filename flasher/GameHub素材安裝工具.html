Game Hub 素材安裝工具

把遊戲圖片素材（.BIN）裝進鍵盤螢幕的外置 Flash · 用 Chrome / Edge 開啟 · macOS 與 Windows 皆可

1. 選擇素材檔

把 .BIN 檔拖到這裡，或點這裡選擇（可一次選多個）
檔案遊戲大小檢查安裝

2. 連接並安裝

鍵盤要用 USB 線連接（接收器、藍牙都不行）
尚未開始

· 先關掉官方網頁驅動和其他會連鍵盤的程式（例如 claude-hop 後台）。
· 螢幕上如果正在玩遊戲，先在遊戲中連按 3 次 Esc 回選單再安裝。
· 檔案一個一個傳，檔案之間會停 2 秒；某個檔卡住會自動重傳（最多 3 次）。中斷不會弄壞螢幕上原有的檔案。
· 裝完在 Game Hub 選單按一下 ↑ 或 ↓，遊戲旁的 NO FILE 會消失。
