Game Hub 素材安裝與 Flash 管理工具

查看鍵盤外置 Flash 現有檔案與剩餘空間 · 單檔刪除或一鍵騰空 · 拖入單一 .ZIP / .BIN 安裝素材

1. 鍵盤外置 Flash 狀態與清理 尚未連接

⚠️ 外置 Flash 檔案較多，原廠列表緩衝（256 位元組）可能未顯示全部檔案；刪除部分檔案後再按「讀取鍵盤 Flash」即可繼續查看其餘檔案。
點擊「讀取鍵盤 Flash」即可查看目前鍵盤外置 Flash 裡已存哪些檔案、剩餘多少空間，並可單檔移除或清空騰空容量（免重刷固件，原廠固件與其他固件亦適用）。
檔案歸屬大小操作

2. 選擇 Game Hub 素材包（推薦拖入 1 個 .ZIP）

把 GameHub-全部素材包.zip 拖到這裡，或點這裡選擇
也支援直接拖入單個或多個 .BIN 素材檔
選檔案遊戲本地大小鍵盤現況檢查安裝

3. 寫入素材與執行紀錄

鍵盤要用 USB 線連接（接收器、藍牙都不行）；操作前請回到選單（遊戲中 2 秒內連按 5 次 Esc）
尚未開始

· 先關掉官方網頁驅動和其他會連鍵盤的程式。
· 先按「讀取鍵盤 Flash」再按「只選缺少／有更新」，會直接比對鍵盤實機 Flash 狀態，只補裝缺少或大小有變動的素材。
· 若要換玩法／刷入別的固件並騰空全部 4 MB 外置空間，可按「一鍵清除 Game Hub 素材」（保留底圖）或「格式化清空整個 Flash」（全部清空）。
· 裝完在 Game Hub 選單按一下 ↑ 或 ↓，遊戲旁的 NO FILE 會消失。
